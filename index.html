🔗 Supabase 云数据库配置

本系统使用 Supabase 作为云端数据库，多人共享同一份数据。
📖 配置步骤：
1. 打开 👉 supabase.com → 点击「Start your project」
2. 用 GitHub 账号登录（你已经有 GitHub 了！）
3. 点击「New Project」→ 填写项目名（如「评分系统」）→ 设置数据库密码 → 选区域（推荐 Northeast Asia）→ 创建
4. 等待 1-2 分钟项目初始化完成
5. 左侧菜单点击「SQL Editor」→ 点击「New Query」→ 粘贴下面的 SQL 并点击「Run」：
CREATE TABLE players ( id TEXT PRIMARY KEY, name TEXT NOT NULL, team TEXT DEFAULT '未分组', created_at TIMESTAMPTZ DEFAULT NOW() ); CREATE TABLE votes ( id BIGSERIAL PRIMARY KEY, player_id TEXT NOT NULL, voter_name TEXT NOT NULL, operation INT DEFAULT 0, management INT DEFAULT 0, communication INT DEFAULT 0, created_at TIMESTAMPTZ DEFAULT NOW(), UNIQUE(player_id, voter_name) ); -- 开启匿名访问权限 ALTER TABLE players ENABLE ROW LEVEL SECURITY; ALTER TABLE votes ENABLE ROW LEVEL SECURITY; CREATE POLICY "允许所有人读取选手" ON players FOR SELECT USING (true); CREATE POLICY "允许所有人创建选手" ON players FOR INSERT WITH CHECK (true); CREATE POLICY "允许所有人更新选手" ON players FOR UPDATE USING (true) WITH CHECK (true); CREATE POLICY "允许所有人删除选手" ON players FOR DELETE USING (true); CREATE POLICY "允许所有人读取投票" ON votes FOR SELECT USING (true); CREATE POLICY "允许所有人创建投票" ON votes FOR INSERT WITH CHECK (true); CREATE POLICY "允许所有人更新投票" ON votes FOR UPDATE USING (true) WITH CHECK (true); CREATE POLICY "允许所有人删除投票" ON votes FOR DELETE USING (true);
6. 左侧菜单点击「Settings」→「API」→ 复制 Project URL 和 anon public key 填入下方
